# 验证说明

**简体中文** · [English](TESTING.en.md)

## 模型无关检查

`scripts/test.ps1` 编译后的应用会分别启动独立检查进程：

| 检查 | 覆盖行为 |
| --- | --- |
| `--appearance-test` | 主题、HEX、透明度、尺寸、左上锚点、取消恢复及范围限制 |
| `--compact-test` | 待机圆圈、展开/收回、5 秒自动收回、录音/处理保持展开、快速反向、结果保留 |
| `--language-key-test` | T 仅录音时注册、中英双向切换、当前输出与保存模式一致、预览保留、排队事件忽略、30 次释放循环、取消/退出释放 |

Windows CI 运行上述检查。它们不加载模型，不访问麦克风，也不模拟向其他应用输入文本。

`-Interactive` 增加 `--window-test`，检查 Ctrl+R 注册、重复显示、输入焦点、卡片/圆圈鼠标穿透、Alt 操作及完全不透明时的穿透。需要交互式 Windows 桌面，先退出正常运行的应用。

`-Stress` 增加 `--stress-test`：预热后 40 次完整动画和 10 次快速反向动画，检查私有内存、GDI/USER 对象、临时位图与定时器释放。测试循环的消息泵存在额外开销，其帧率不是实际桌面刷新率测量。

## 完整语音链路

`-WithRuntime` 增加 `--self-test` 与 `--translation-test`，需已准备兼容引擎、模型、麦克风及中文 SAPI 语音。涵盖音频编码、设备开关、短预览、最终识别、进行中的预览取消、取消后再次识别、整理、翻译的数字/否定/问题/术语、长段口述和模型卸载。不得与正在使用同一端口的正常应用同时运行。

## 首个版本的本地观察

开发设备上，模型卸载后的界面工作集约 43 MB、私有内存约 25 MB；8 秒待机 CPU 样本接近 0%，启动至输入空闲约 816 毫秒。动画压力测试 GDI 和 USER 对象增长均为 0，预热后私有内存增加约 3.33 MB。上述数字不包含模型、不能代表所有设备，也不能证明永不崩溃。
